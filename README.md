# SSL_TDOA_MLTDOA_Benchmark
# Sound Source Localization (SSL): Conventional GCC-PHAT vs. ML (FFNN) 

The dataset is described by DOI: 10.21203/rs.3.rs-8372479/v1

This repository contains the supporting code and experimental evaluation for the research manuscript on Sound Source Localization using compact 4-microphone circular array across multi-distance indoor environments (1m, 3m, 5m).

## 📌 Overview
The pipeline benchmarks:
1. **Conventional TDOA (GCC-PHAT):** Cross-correlation delay estimation mapped to theoretical microphone array geometry signatures.
2. **Machine Learning Approach (FFNN):** A 3-layer Feed-Forward Neural Network trained on pairwise TDOA feature vectors.

The detailed code is attached in python notepad "SSL_TDOA_MLTDOA_Benchmark.ipynb"
